# Backpack Ball Battler

Portrait HTML5 prototype: backpack grid + Matter.js ball launcher + merging + auto-battler castle fight (you vs. AI, 3 rounds).

Open `index.html` in a browser (no build step; Matter.js is vendored in `lib/`).

- Drag cards onto your backpack (bottom). Same type + level merges (up to Lv3). Drag placed units to move/swap/merge.
- Drop upgrade cards anywhere on your backpack zone to upgrade the launcher.
- Drag/touch your backpack area to aim the launcher. Press START BATTLE.
- Balance numbers: `js/config.js`.
